# Registro de Provas

Site simples para registrar provas com motivo, descrição, imagens e vídeos.

## Como usar

1. Execute `npm install`
2. Execute `npm start`
3. Abra `http://localhost:3000`
4. Preencha o formulário para adicionar provas

## Recursos

- Motivo e descrição da prova
- Upload de arquivo de imagem ou vídeo
- Link externo para mídia
- Provas salvas localmente em `data/proofs.json`
- Uploads salvos em `uploads/`
